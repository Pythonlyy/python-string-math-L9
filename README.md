# ✨ String Math in Python – `+` and `*`

In Python, you can use math operators like `+` and `*` on strings!
This lets you combine or repeat text in fun and creative ways.

---

## 💡 What You Can Do

| Operator | Meaning            | Example      | Result     |
| -------- | ------------------ | ------------ | ---------- |
| `+`      | Join (concatenate) | `"Hi" + "!"` | `"Hi!"`    |
| `*`      | Repeat             | `"Hi" * 3`   | `"HiHiHi"` |

---

## 💻 Example with Explanation

```python
print("Hello" + " " + "world")    # Joining strings
print("Python!" * 3)              # Repeating strings
```

### 🔈 Output

```
Hello world
Python!Python!Python!
```

---

### 📌 Key Notes

* You **can’t** use `-`, `/`, or `**` on strings — only `+` and `*`
* `+` joins two strings together (no space unless you add one!)
* `*` repeats the string the number of times you specify

---

## 🧪 Try It Yourself

```python
word = "Hey"
emoji = "🔥"

print(word * 2)
print(emoji * 5)
print(word + " there!")
```

### 🔈 Expected Output

```
HeyHey
🔥🔥🔥🔥🔥
Hey there!
```
